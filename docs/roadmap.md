## How to help

To work on a roadmap item:

1. Check the [open issues](https://github.com/{{OWNER}}/{{REPO}}/issues) first. If the item has an issue, comment on it.
2. If it doesn't, open one with the [feature request form](https://github.com/{{OWNER}}/{{REPO}}/issues/new?template=feature_request.yml). Name the roadmap item and describe the problem it solves.
3. Agree on the approach in the issue before you start a large change.

If you'd rather start small, pick up an open issue labeled [`good first issue`](https://github.com/{{OWNER}}/{{REPO}}/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). An issue about what was slow, confusing or missing is just as useful as code.

See the [contributing guide](../CONTRIBUTING.md) for how to get set up and how pull requests work.
